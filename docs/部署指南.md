## 1. 开发环境部署

### 1.1 环境要求
| 组件 | 版本 | 说明 |
|------|------|------|
| Python | 3.7+ | 推荐3.8-3.10 |
| CUDA | 11.0+ | GPU训练必需 |
| cuDNN | 8.0+ | GPU加速必需 |

### 1.2 完整安装步骤

```bash
# 1. 克隆/进入项目目录
cd 项目路径

# 2. 创建虚拟环境
python -m venv venv

# 3. 激活虚拟环境
# Windows:
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

# 4. 升级pip
pip install --upgrade pip

# 5. 安装PyTorch（根据CUDA版本）
# CUDA 12.1:
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
# CUDA 11.8:
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu118
# CPU only:
pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu

# 6. 安装项目依赖
pip install -r requirements.txt

# 7. 验证安装
python main.py check
```

## 2. 生产环境部署

### 2.1 API服务部署（推荐）

```bash
# 1. 安装依赖
pip install gunicorn  # Linux
# 或
pip install waitress  # Windows

# 2. 启动API服务
# Linux (gunicorn):
gunicorn -w 4 -b 0.0.0.0:5000 web.api:app

# Windows (waitress):
waitress-serve --port=5000 web.api:app

# 3. 使用Nginx反向代理（可选）
```

### 2.2 Nginx配置示例

```nginx
server {
    listen 80;
    server_name reid.example.com;

    # API服务
    location /api/ {
        proxy_pass http://127.0.0.1:5000/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_read_timeout 300s;
        client_max_body_size 100m;
    }

    # Web界面
    location / {
        proxy_pass http://127.0.0.1:8501/;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_read_timeout 86400s;
    }
}
```

### 2.3 systemd服务配置

```ini
[Unit]
Description=Person ReID API Service
After=network.target

[Service]
Type=simple
User=reid
WorkingDirectory=/opt/reid
Environment="PYTHONPATH=/opt/reid"
ExecStart=/opt/reid/venv/bin/python web/api.py --port 5000
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

### 2.4 安全配置

```bash
# 1. 防火墙配置
# 仅开放必要端口
sudo ufw allow 5000/tcp  # API服务
sudo ufw allow 8501/tcp   # Web界面
sudo ufw enable

# 2. HTTPS配置（使用Let's Encrypt）
sudo apt install certbot python3-certbot-nginx
sudo certbot --nginx -d reid.example.com
```

## 3. Docker部署

### 3.1 Dockerfile

```dockerfile
FROM pytorch/pytorch:2.0.0-cuda11.7-cudnn8-runtime

WORKDIR /app

# 安装系统依赖
RUN apt-get update && apt-get install -y \
    libgl1-mesa-glx \
    libglib2.0-0 \
    && rm -rf /var/lib/apt/lists/*

# 复制项目文件
COPY . .

# 安装Python依赖
RUN pip install --no-cache-dir -r requirements.txt

# 暴露端口
EXPOSE 5000 8501

# 默认启动API服务
CMD ["python", "web/api.py", "--port", "5000"]
```

### 3.2 docker-compose.yml

```yaml
version: '3.8'

services:
  reid-api:
    build: .
    container_name: reid-api
    ports:
      - "5000:5000"
    volumes:
      - ./checkpoints:/app/checkpoints
      - ./data:/app/data
      - ./logs:/app/logs
    environment:
      - CUDA_VISIBLE_DEVICES=0
      - TORCH_HOME=/app/.cache/torch
    command: python web/api.py --port 5000
    restart: unless-stopped
    deploy:
      resources:
        reservations:
          devices:
            - driver: nvidia
              count: 1
              capabilities: [gpu]

  reid-web:
    build: .
    container_name: reid-web
    ports:
      - "8501:8501"
    volumes:
      - ./checkpoints:/app/checkpoints
      - ./data:/app/data
    environment:
      - STREAMLIT_SERVER_PORT=8501
    command: streamlit run web/app.py --server.port 8501 --server.address 0.0.0.0
    restart: unless-stopped
    depends_on:
      - reid-api
```

### 3.3 构建和运行

```bash
# 构建镜像
docker build -t reid-system .

# 使用docker-compose启动
docker-compose up -d

# 查看日志
docker-compose logs -f

# 停止服务
docker-compose down

# 单独启动API服务
docker run -d --gpus all -p 5000:5000 -v ./checkpoints:/app/checkpoints reid-system
```

## 4. Windows部署

双击 `一键配置环境.bat`，脚本将自动完成：
1. 检测Python版本
2. 创建虚拟环境
3. 安装PyTorch（CPU版本）
4. 安装所有依赖

### 4.2 手动安装

```powershell
# 1. 打开PowerShell/CMD，进入项目目录
cd 项目路径

# 2. 创建虚拟环境
python -m venv venv

# 3. 激活虚拟环境
.\venv\Scripts\activate

# 4. 安装依赖
pip install -r requirements.txt

# 5. 启动服务
# Web界面
streamlit run web/app.py
# 或
python main.py web
```

### 4.3 启动脚本

| 脚本 | 功能 | 使用方式 |
|------|------|----------|
| `主菜单.bat` | 展示功能菜单 | 双击运行 |
| `一键启动.bat` | 一键启动系统 | 双击运行 |
| `启动Web界面.bat` | 直接启动Web | 双击运行 |
| `启动训练.bat` | 启动模型训练 | 双击运行 |
| `环境检查.bat` | 检查运行环境 | 双击运行 |

### 4.4 注册为Windows服务

```powershell
# 使用NSSM（Non-Sucking Service Manager）
# 下载nssm: https://nssm.cc/download

# 注册API服务
nssm install ReIDAPI "python" "web/api.py --port 5000"
nssm set ReIDAPI AppDirectory "C:\项目路径"
nssm start ReIDAPI
```

### 6.3 健康检查端点

```python
@app.route('/health')
def health():
    """健康检查，返回详细状态"""
    status = {
        'status': 'ok',
        'version': '2.0.0',
        'gpu_available': torch.cuda.is_available(),
        'model_loaded': True,
        'gallery_size': len(getattr(infer, 'gallery_ids', [])),
        'memory_usage': {},
    }
    
    if torch.cuda.is_available():
        status['memory_usage']['gpu_used'] = torch.cuda.memory_allocated() / 1024**3
        status['memory_usage']['gpu_cached'] = torch.cuda.memory_reserved() / 1024**3
    
    return jsonify(status)
```

## 8. 故障排除

### 8.1 常见部署问题

| 问题 | 原因 | 解决方法 |
|------|------|----------|
| PyTorch CUDA不可用 | CUDA版本不匹配 | 重新安装对应版本的PyTorch |
| OpenCV导入失败 | 缺少系统库 | `pip install opencv-python-headless` |
| 端口被占用 | 其他服务使用同一端口 | 修改端口号或关闭其他服务 |
| 内存不足 | 图片太大或batch太大 | 减小batch size或图片尺寸 |
| 模型加载失败 | 模型文件损坏 | 重新训练或下载模型 |
| 中文路径问题 | Windows编码 | 使用英文路径 |

### 8.2 日志分析
