## 4. 使用真实数据集训练

### 4.1 准备数据集

**Market-1501** 是行人重识别领域最常用的数据集，包含：
- 1501个不同身份
- 32,668张训练图片
- 19,732张测试图片
- 3,368张查询图片

### 4.2 自动下载数据集

```bash
python train.py --download --epochs 60
```

**注意**：
- 数据集约250MB，下载可能需要5-10分钟
- 如果自动下载失败，请手动下载：
  1. 访问：https://rdm.ding.pku.edu.cn/dataset/market1501
  2. 或访问：https://www.kaggle.com/datasets/pengcw/market1501
  3. 下载 `Market-1501-v15.09.15.zip`
  4. 解压到 `./data/Market-1501` 目录

### 4.3 训练参数说明

```bash
python train.py --download \
    --epochs 60 \        # 训练轮数（推荐60）
    --batch_size 32 \     # 批次大小（显存不足可减小到16）
    --lr 0.0003 \        # 学习率
    --feat_dim 512 \      # 特征维度
    --save_dir ./checkpoints  # 模型保存目录
```

### 4.4 GPU训练建议

| GPU显存 | batch_size | epochs | 预计时间 |
|---------|------------|--------|----------|
| 4GB | 16 | 60 | ~1小时 |
| 8GB | 32 | 60 | ~30分钟 |
| 16GB+ | 64 | 60 | ~15分钟 |

### 4.5 CPU训练（不推荐）

如果没有GPU，可以在CPU上训练，但速度会非常慢：
```bash
python train.py --download --epochs 30 --batch_size 8
```

> ⚠️ CPU训练可能需要数小时到数天，请耐心等待。

## 6. 使用训练好的模型

### 6.1 模型文件位置

训练完成后，模型保存在 `./checkpoints` 目录：

```
checkpoints/
├── best_model.pth    # 最佳模型（Rank-1最高）
└── final_model.pth   # 最终模型（最后一个epoch）
```

### 6.2 在Web界面中使用

1. 将 `best_model.pth` 复制到项目根目录
2. 修改 `reid_model.py`，加载预训练权重：

```python
# 在 ReIDSystem.__init__ 中添加：
if model_path:
    checkpoint = torch.load(model_path, map_location=self.device)
    if 'state_dict' in checkpoint:
        self.model.load_state_dict(checkpoint['state_dict'])
    else:
        self.model.load_state_dict(checkpoint)
```

3. 启动Web界面：
```bash
streamlit run app.py
```

### 6.3 评估已有模型

```bash
python train.py --eval_only --model_path checkpoints/best_model.pth
```

## 7. 常见问题

### Q1: 训练时显存不足怎么办？

**解决方法**：
```bash
# 减小batch_size
python train.py --download --batch_size 16
```

### Q2: 下载数据集失败怎么办？

**手动下载步骤**：
1. 访问 Kaggle: https://www.kaggle.com/datasets/pengcw/market1501
2. 下载 zip 文件
3. 解压到 `./data/Market-1501-v15.09.15`
4. 重命名文件夹为 `Market-1501`

### Q3: 训练中断了怎么办？

可以断点续训，修改代码加载已有checkpoint继续训练。

### Q4: 如何提高识别精度？

1. 增加训练轮数（60-100 epochs）
2. 使用更大的特征维度（768或1024）
3. 使用更先进的主干网络（如OSNet、ResNeXt）
4. 使用更多数据增强
5. 使用难例挖掘（hard triplet mining）

### Q5: CUDA out of memory

确保没有其他程序占用GPU显存，或重启Python环境后减小batch_size。
