# 快速开始指南

本文档帮助您快速上手使用本系统。

---

## 前置条件

- Python 3.7+
- 可选：NVIDIA GPU + CUDA 11.0+
- 推荐：8GB+ 内存

---

## 一、环境安装

### 步骤1：创建虚拟环境（推荐）

```bash
# Windows
python -m venv venv
venv\Scripts\activate

# Linux/macOS
python3 -m venv venv
source venv/bin/activate
```

### 步骤2：安装依赖

```bash
# 基础安装
pip install -r requirements.txt

# 如需GPU加速（根据CUDA版本选择）
# CUDA 11.8
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu118
# CUDA 12.1
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
```

### 步骤3：验证安装

```bash
python main.py check
```

---

## 二、30秒快速体验

```bash
# 1. 环境检查
python main.py check

# 2. 启动Web界面（浏览器打开 http://localhost:8501）
python main.py web

# 3. 或者启动API服务
python main.py api
```

---

## 三、训练模型

### 快速演示训练
```bash
# 无需数据集，自动生成演示数据
python main.py train --demo --epochs 5
```

### 完整训练
```bash
# 最佳配置推荐
python main.py train --backbone osnet --use_circle_loss --use_weather_aug --use_cosine_annealing --epochs 100 --batch_size 64
```

### 训练参数说明
```bash
python train.py --help
```

---

## 四、人员搜索

### 准备底库
将待搜索人员图片放入 `rescue_gallery/` 目录。

### 执行搜索
```bash
# 搜索模式
python main.py inference --mode search --query 查询图片.jpg --images rescue_gallery/ --top_k 10
```
